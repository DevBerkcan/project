# Gentle Group Studios

Die Website von Gentle Group Studios ist eine React-/TypeScript-Anwendung mit Vite. Sie beschreibt individuelle Software, Web-Apps, Websites, KI-Lösungen, Automatisierung und die GentleSuite-Produkte.

## Entwicklung

```bash
npm install
npm run dev
```

Der Entwicklungsserver läuft standardmäßig unter `http://localhost:3000`.

## Qualitätssicherung

```bash
npm run lint
npm test
npm run build
```

Die Tests prüfen die zentrale Inhaltsstruktur und verhindern, dass entfernte Template-Projekte, ungeprüfte Kennzahlen, Awards, Standorte oder Platzhalter-Links wieder in den Produktionscode gelangen.

## Inhalte und Quellen

Öffentlich verwendete Angebots- und Produktinhalte orientieren sich an der bestehenden Gentle-Group-Website. Kundenprojekte, Testimonials, Teamangaben, Kennzahlen und rechtliche Texte werden erst nach Prüfung und Freigabe ergänzt.
